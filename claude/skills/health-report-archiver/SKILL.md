# 医学检查报告归档与分析

## 管道概览

```
原始图片/文档 → [document-ingest] → 文本内容 → 分类识别 → 重命名归档 → 历史对比 → 综合评估报告
                    (格式转换)                  (本技能)
```

格式转换委托给 `document-ingest` skill（自动路由：图片→rapid-ocr MCP，PDF→markdown，XLSX→AST）。本技能负责后续所有医学特定环节。

## 工作流程

### Phase 1: 发现档案结构

1. 在用户提供的档案根目录下查找 `README.md`、`*信息一览*.md` 或目录列表
2. 识别以下关键路径：
   - **原图目录**：存放待处理原始图片（通常是 `99_原图/` 或用户指定目录）
   - **分类子目录**：`01_生殖内分泌与超声/`、`02_免疫与凝血/` 等（参考 [category_mapping.md](references/category_mapping.md)）
   - **综合报告目录**：存放评估报告的顶层目录（通常是 `00_综合评估总报告/`）
   - **患者信息文件**：包含病史、用药、既往妊娠等背景信息的文件
3. 如果档案结构与标准不同，以实际结构为准，并向用户确认

### Phase 2: 格式转换

1. 列出原图目录中所有待处理文件
2. 对每个文件调用 `document-ingest` 路由或直接用 `rapid-ocr MCP` 做 OCR
3. 收集所有 OCR 文本，记录每个文件的日期、内容类型

### Phase 3: 分类识别

根据 OCR 内容识别每份文档的类型，参考 [category_mapping.md](references/category_mapping.md) 中的关键词映射：

- 超声/影像类 → `01_生殖内分泌与超声/`
- 免疫/凝血化验 → `02_免疫与凝血/`
- HCG/孕酮/E2 → `03_妊娠激素/`
- 血常规/生化/体检 → `05_全身综合体检/`
- 门诊病历/处方 → `07_其他专科/`
- 等

如果一个文档包含多种类型（如门诊病历同时涉及多项化验），优先归入 `07_其他专科/`。

### Phase 4: 归档

**文件命名规范：**

```
YYYY-MM-DD_内容描述原始单据.jpg          # 主图
YYYY-MM-DD_内容描述补充原始单据_NN.jpg   # 同次补充图
YYYY-MM-DD_内容描述报告.md              # OCR 提取报告
```

**操作步骤：**
1. 从 OCR 文本中提取检查/就诊日期作为文件名日期
2. 用中文简述内容（如"产科超声""妊娠激素""门诊复诊病历"）
3. 复制原图到对应分类子目录，按规范重命名
4. 生成 OCR 报告 .md 文件（模板参考 [report_templates.md](references/report_templates.md)）
5. 原图目录中的原始文件保留不动

### Phase 5: 收集历史上下文

1. 读取患者信息文件（病史、诊断、用药、既往妊娠等）
2. 读取综合报告目录下最近 3-5 份评估报告
3. 读取与新检查相关的历史化验/超声报告
4. 提取关键趋势数据（如 HCG 序列、孕酮序列、超声参数等）

### Phase 6: 综合分析

遵循以下分析原则（详见 [report_templates.md](references/report_templates.md)）：

1. **结论先行**：先给关键判断，再补数据支撑
2. **趋势优于单点**：一个值的绝对水平不如变化方向重要
3. **跨系统关联**：超声+激素+免疫+凝血不是孤立的，要串联解读
4. **区分信号与噪声**：不是每个化验波动都有临床意义
5. **标记缺口**：明确指出应该监测但缺失的项目
6. **区分来源**：本地依据 vs 模型判断 vs 外部来源

**用药分析：**
- 对比新旧方案的变化，解释临床推演逻辑
- 注意病历记录与患者自述之间的差异，提醒核实
- 对新药物标注安全监测要点

### Phase 7: 撰写综合评估报告

按模板写入综合报告目录。报告结构：

1. **本轮最核心结论**（3-6 条要点）
2. **新增信息逐项解读**（每份新文档一段）
3. **分系统评估**（带历史趋势表）
4. **用药方案分析**（如有变化）
5. **具体建议**（按优先级排列 + 症状警戒线）
6. **一句话总评**

## 交互原则

- **不确定时主动确认**：药物剂量疑义、文档分类模糊、日期冲突等情况，向用户核实而不猜测
- **不遗漏**：原图目录中每张图片都要处理，OCR 失败的尝试替代方法（如用户手动输入）
- **及时修正**：如果用户指出之前报告漏掉了某份数据，立即修正所有受影响的历史报告
