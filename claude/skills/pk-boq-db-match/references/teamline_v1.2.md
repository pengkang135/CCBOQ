## 模型分层铁律

| 层级 | 角色 | 模型 | 职责 | 触发条件 |
|------|------|------|------|---------|
| ① | 设计者 | Opus | 定规则/阈值/路由/prompt模板 | 一次性/规则更新时 |
| ② | 路由 | Python | 双源检索 + 候选合并 + 分档 + 预过滤 + known_gap 路由 | 每次运行（0 token） |
| ③ | 执行者 | Haiku | 星型并行批量匹配（使用完整 matcher_prompt.md） | 2-3 候选的常规项 |
| ④ | 执行者 | Sonnet | 重判升级项 + 复杂项【强制闸门】 | 4+ 候选 / conf<0.6 升级 |
| ⑤ | 后处理 | Python | 单位换算（kg↔t, m2↔m3, 混凝土密度, 维度兼容校验）【新增·0 token】 | ③④ 产出后全部项 |
| ⑥ | 审核+重试 | Python + Sonnet | 跨模型比对 + 低分重试回路 + no_match 补搜【强制闸门】 | ⑤ 完成后全部项 |
| ⑦ | 决策者 | Opus | 只裁争议【强制闸门】 | 冲突池 / 重试失败 / 零候选 / 双源矛盾 |
| ⑧ | 回写 | Python | 写回 + 验证 + 报告 | 全部定案后 |

**核心铁律：换模型 = 独立信号。** 执行 Haiku / 校验 Sonnet / 决策 Opus。同模型自我确认偏差——执行器误判必须由不同模型的校验层拦截。

**v1.2 新增铁律：低分和未匹配项必须退回 LLM 重判，不得直接丢弃。** sim<0.6 或 no_match → 扩大检索 → 换模型重判 → 最多 2 轮重试 → 仍未通过 → ⑦ Opus 终裁。

**v1.2 新增铁律：单位换算必须在回写前完成。** BOQ unit ≠ matched unit 时，Python 先判断换算公式可行性（有厚度→可换算 / 维度不兼容→标记），换算成功的标 estimated，无法换算的标 unit_gap。

## ② 检索双源说明

| 检索源 | 调用方式 | 强项 | 弱项 | 命中率 |
|--------|---------|------|------|--------|
| CostSpread API | `docker exec` → `/api/rates/search` | 物料级（混凝土标号/钢材规格/卫浴） | 施工活动/复杂系统 | ~60% |
| MongoDB | pymongo 直连 | 施工活动/跨语言语义匹配 | 物料精确规格不如 CostSpread | ~75% |

合并: CostSpread 优先，MongoDB 兜底，按 `_id` 去重。

## 与 v1.1 的区别
