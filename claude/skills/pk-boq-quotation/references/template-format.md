# 上传模板格式参考

基于 `static/显示和上传模板/市场询价表.xlsx` 的 "3.1价格表" sheet。

## 表头列 (A-O)

| 列 | 表头 | 说明 |
|----|------|------|
| A | 编号 | 序号或代码标识 |
| B | 专业 | 专业分类（劳务分包/材料/设备等） |
| C | 名称 | 材料/服务名称 |
| D | 项目特征 | 规格、型号、性能参数 |
| E | 单位 | 计量单位 (m³, kg, 工日, m²等) |
| F | 除税单价 | 不含税单价 |
| G | 税金 | 税额 |
| H | 含税单价 | 含税单价 |
| I | 日期 | 报价日期 |
| J | 币种 | 货币类型 |
| K | 供应商 | 供应商名称 |
| L | 联系人 | 联系人姓名 |
| M | 电话 | 联系电话 |
| N | 地址 | 供应商地址 |
| O | 备注 | 附加信息 |

## HTML报告对应列

HTML报告中的表格使用以上全部15列，与Excel模板保持一致。

数据行按供应商分组，每组先显示供应商信息摘要，然后列出该供应商的所有报价条目。
