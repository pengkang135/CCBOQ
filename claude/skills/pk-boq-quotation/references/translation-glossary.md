## 翻译

非英文（泰文、阿拉伯文等）翻译为中文。材料名保留英文术语并补中文译名；技术参数保持原文。常见泰文对照：

- `คอนกรีตหยาบ` → 粗混凝土（垫层）
- `คอนกรีตโครงสร้าง` → 结构混凝土
- `คอนกรีตกำลังอัดสูง` → 高强混凝土
- `คอนกรีตโครงสร้างกันซึม` → 防水结构混凝土
- `พื้นคอนกรีตอัดแรง` → 预应力混凝土楼板
- `ราคาสุทธิ` → 净价
- `ใบเสนอราคา` → 报价单

**泰国佛历年 = 公历年 + 543**，日期换算勿漏。
