# BOQ 工程造价约定

## 编号体系

- **OM**（Omission）：遗漏项目
- **DI**（Description Incomplete）：描述不完善
- 编号独立递增，贯穿整个分析

## DB 合同特殊性

- FIDIC 黄皮书 DB 模式下，清单不是计价依据而是报价统一口径
- 清单工程量以**设计量列**为准（非招标量列）
- 设计院清单体系可能显著不同于标准招标清单（条目数、分类细度）
- 报告必须注明合同模式和清单范围

## 数量偏差比较基准

- **比较对象**：设计院清单工程量 vs 设计方案报告/技术规格中的工程量（同一来源，内部自洽性检查）
- **不对标招标清单工程量**：招标清单工程量为投标人自填，不构成设计依据
- 偏差标注「设计清单量 vs 设计报告量」，不标注「设计量 vs 招标量」

## 5 类描述完整性扫描

| 问题类型 | 检查规则 | 典型影响 |
|---------|---------|---------|
| 混凝土缺强度等级 | m³ 计量 + 描述无 C25/C30/C40 等 | 每级差 8-12% 单价 |
| 回填料缺材质/来源 | 回填/填筑类 + 未标注材质/含泥量 | 本地料 vs 进口料差 2-3 倍 |
| LS 总价不可分解 | LS 单位 + 无组成说明 | 无法校核报价合理性 |
| 设备缺规格参数 | set/No. 单位 + 无型号/技术参数 | 型号不确定导致报价离散 |
| 钢筋缺等级 | t 计量 + 无 400/500MPa 等级 | 高强 vs 普通差 5-10% |

## 概算指标公式

```
单位指标 = 主导工程量 / 特征尺度
```

特征尺度（需从设计文件提取）：

| 工程类型 | 典型特征尺度 |
|---------|------------|
| 码头 | 岸线长度 (m)、码头面积 (m²) |
| 堆场/道路 | 铺面面积 (m²)、路线长度 (km) |
| 房建 | 建筑面积 (m²)、层数 |
| 疏浚 | 疏浚量 (m³)、面积 (m²) |
| 地基处理 | 处理面积 (m²)、桩数 (根) |
| 管沟/围栏 | 延米 (m) |

## 方案对比框架

若 BOQ 包含多个方案（OPTION 1/2），按方案分别提取指标，生成对比表：

```
| 指标 | 方案1 | 方案2 | 差异 |
|------|------|------|------|
| 桩基用量 | X t/m | Y 根/m | — |
| 单位岸线混凝土量 | X m³/m | Y m³/m | ±Z% |
```

同类工程内部指标偏差 >30% 的条目标记为需复核。

## 疑问函规范

### 两阶段工作流

1. **先出 MD 中文版**：表格形式，10列表头与正式 Excel 完全一致，供内部确认
2. **后出 Excel 英文版**：用户确认后翻译生成，FHDI 10列格式，对外发送

### 10列格式

| ITEM | Date | Disciplines | BOQ Ref. | Attachment Ref. | QUESTION | ASK BY | ANSWER | ANSWER BY | ANSWER DATE |

### 写作规则

- **Attachment Ref.**：写清单文件名或设计报告章节号
- **Question**：简明扼要，不写 OM/DI 编号，不展开长篇背景
- **Ask By**：固定为造价工程师全名「Peng Kang」
- 数量比较：设计清单量 vs 设计报告量（同源），不比招标清单

### 项目信息头

- PROJECT / PACKAGE / EMPLOYER / QS / EMAIL TO / DATE
