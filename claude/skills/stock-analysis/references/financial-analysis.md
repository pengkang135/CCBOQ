# 财务数据提取与分析框架

## 数据源文件

在中间格式目录下，每个公司应有以下 Markdown 文件：

| 文件 | 来源 | 内容 |
|------|------|------|
| `{公司}_主要财务指标.md` | `{code}_main_report.xls` | 核心财务指标时间序列（营收/利润/EPS/ROE等） |
| `{公司}_利润表.md` | `{code}_benefit_report.xls` | 完整利润表（营业收入→净利润） |
| `{公司}_现金流量表.md` | `{code}_cash_report.xls` | 经营活动/投资/筹资现金流 |
| `{公司}_资产负债表.md` | `{code}_debt_report.xls` | 资产/负债/权益明细 |
| `{公司}_自定义指标.md` | `{code}_diy_report.xls` | 自定义财务比率 |
| `{公司}_2025年度报告.md` | PDF年报 | 完整年报全文文本 |
| `{公司}_2025半年度报告.md` | PDF半年报 | 半年报全文文本 |
| `{公司}_2026Q1报告.md` | PDF季报 | 最新季报全文文本 |

## 数据提取方法

### 从 Markdown 表格提取

所有 XLS 转换的 MD 文件格式为：Markdown 表格，第一行为表头（科目\时间），第一列为指标名，后续列为各报告期数据。

**提取步骤**:
1. 读取 MD 文件，定位 `##` 标题下的表格
2. 解析表头行获取日期列
3. 逐行提取指标名 → 时间序列映射
4. 数值统一转换为 float（去除"亿""万"单位，还原为实际数值）

### 关键提取指标

**成长性指标**:
- 营业总收入 / 同比增长率（近5年）
- 净利润 / 扣非净利润 / 同比增长率
- 近3年/5年 CAGR

**盈利能力**:
- 毛利率 = (营业收入 - 营业成本) / 营业收入
- 净利率 = 净利润 / 营业收入
- ROE（加权平均）= 净利润 / 平均净资产
- ROA、ROIC（如有）

**财务安全**:
- 资产负债率
- 流动比率 / 速动比率
- 有息负债率
- 经营现金流 / 有息负债

**盈利质量**:
- 扣非净利润 / 净利润（近5年均值）
- 经营现金流 / 净利润
- 应收账款 / 营业收入比值及趋势

**运营效率**:
- 应收账款周转天数
- 存货周转天数
- 总资产周转率

### 从年报全文文本提取

年报/半年报/季报 PDF 转 MD 后，重点扫描以下章节：
- **管理层讨论与分析**（MD&A）：业绩回顾、经营策略、未来展望
- **主营业务分析**：收入构成、毛利率变动原因
- **研发投入**：研发费用金额、研发费用率、在研项目
- **行业格局与趋势**：公司对行业的判断
- **风险因素**：公司自述的主要风险
- **重大事项**：分红、担保、诉讼、关联交易等

提取方法：搜索关键词定位，截取相关段落。关键词包括：
- `"管理层讨论与分析"` / `"经营情况讨论与分析"`
- `"主营业务分析"` / `"收入构成"`
- `"研发投入"` / `"研发费用"`
- `"核心竞争力"` / `"技术优势"`
- `"风险因素"` / `"可能面对的风险"`
- `"行业格局"` / `"行业趋势"`

## 异常检测

分析时注意以下异常信号：
- 净利润与经营现金流持续背离（盈利质量差）
- 应收账款增速显著高于营收增速（渠道压货）
- 存货大幅攀升（滞销风险）
- 商誉占总资产比例过高（减值风险）
- 毛利率突然大幅波动（业务结构变化或非经常性因素）
- 非经常性损益占净利润比例过高
- 大额资产减值或信用减值
- 研发费用资本化率异常（调节利润）

## 分析输出格式

Phase 1 完成后生成结构化分析摘要，包含：
1. 近5年核心指标数据表（营收/净利润/毛利率/净利率/ROE/经营现金流）
2. 同比增长率趋势
3. 财务健康度评分（红/黄/绿）
4. 年报关键信息摘要（5-10条要点）
5. 异常信号清单
