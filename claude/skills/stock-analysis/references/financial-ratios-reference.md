# 财务指标速查表

## 核心公式

### 成长性指标

| 指标 | 公式 | 说明 |
|------|------|------|
| 营收同比增长率 | (本期营收 - 上年同期营收) / 上年同期营收 | |
| 净利润同比增长率 | (本期净利润 - 上年同期净利润) / 上年同期净利润 | 注意扣非 |
| 3年CAGR | (末期/基期)^(1/3) - 1 | 消除单年波动 |
| 5年CAGR | (末期/基期)^(1/5) - 1 | |

### 盈利能力

| 指标 | 公式 | 说明 |
|------|------|------|
| 毛利率 | (营业收入 - 营业成本) / 营业收入 | 越高越好，需看趋势 |
| 净利率 | 净利润 / 营业收入 | |
| ROE（加权） | 净利润 / 平均归母净资产 | 杜邦分解 |
| ROA | 净利润 / 平均总资产 | |
| ROIC | NOPAT / 投入资本 | 衡量真实资本回报 |

### 财务安全

| 指标 | 公式 | 警戒线 |
|------|------|--------|
| 资产负债率 | 总负债 / 总资产 | >70%需关注 |
| 流动比率 | 流动资产 / 流动负债 | <1 危险 |
| 速动比率 | (流动资产-存货) / 流动负债 | <0.5 危险 |
| 有息负债率 | 有息负债 / 总资产 | >50%需关注 |
| 利息覆盖倍数 | EBIT / 利息费用 | <3 需关注 |

### 盈利质量

| 指标 | 正常范围 | 警戒信号 |
|------|---------|---------|
| 扣非净利润/净利润 | >80% | 持续<70%警惕 |
| 经营现金流/净利润 | >0.8 | 持续<0.5 质量差 |
| 应收账款/营收 | 行业差异大 | 持续上升需关注 |

### 运营效率

| 指标 | 公式 |
|------|------|
| 应收账款周转天数 | 365 × 平均应收 / 营收 |
| 存货周转天数 | 365 × 平均存货 / 营业成本 |
| 总资产周转率 | 营收 / 平均总资产 |

## 行业基准值

不同行业的财务特征差异巨大，分析时必须结合行业特点：

| 行业 | 典型毛利率 | 典型净利率 | 典型ROE | 典型负债率 | 典型PE中枢 |
|------|-----------|-----------|---------|-----------|-----------|
| 创新药 | 70-90% | 15-30% | 10-20% | 20-40% | 40-70x |
| 医疗器械 | 60-80% | 20-35% | 15-25% | 20-35% | 30-50x |
| 半导体设计 | 35-55% | 10-25% | 8-20% | 15-35% | 40-80x |
| 半导体制造 | 20-40% | 5-15% | 5-12% | 30-50% | 20-40x |
| PCB/封装 | 15-30% | 5-12% | 5-12% | 35-55% | 15-30x |
| 消费电子 | 20-35% | 5-10% | 8-18% | 35-55% | 15-25x |
| 新能源 | 20-35% | 5-15% | 10-25% | 50-70% | 15-30x |

## 数据单位处理

XLS 转换的 MD 中数值已自动处理单位：
- `X.XX亿` → 在提取时还原为实际数值（×10⁸）
- `X.XX万` → 还原（×10⁴）
- 百分比保留为数值（如 21.78% → 0.2178）
- 元保留原始值

## 常见陷阱

1. **非经常性损益干扰**：某季度利润暴增可能是变卖资产而非经营改善，务必核对扣非数据
2. **会计政策变更**：同一指标前后不可比（如收入确认方式变更）
3. **并购并表**：营收增长 ≠ 内生增长
4. **季节性因素**：Q4 营收普遍偏高（中国公司年底冲量）
5. **股份支付**：非现金费用，影响利润但不影响现金流
6. **研发资本化**：资本化率变动可能调节利润
