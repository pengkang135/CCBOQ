# 综合研判方法论

## 信息整合框架

将 Phase 1（财报事实）和 Phase 2（外部信息）的发现整合为统一视图：

```
财报数据（硬事实）──┐
                    ├── 交叉验证 → 综合研判 → 报告输出
网络调研（软信息）──┘
```

## 交叉验证清单

对每条关键论断，检查是否有多来源支持：

| 论断 | 财报证据 | 研报证据 | 行业数据 | 雪球讨论 | 一致性 |
|------|---------|---------|---------|---------|--------|
| 例：营收增长强劲 | Q1同比+20% | 3家券商看好 | 行业增速15% | 多数认可 | 高 |
| 例：毛利率承压 | 毛利率-3ppt | 1家提及 | 原材料涨价 | 讨论激烈 | 中 |

**一致性评分**：
- **高** — 3+ 独立来源互相印证
- **中** — 2 来源支持，或来源权威性不足
- **低** — 仅单一来源，或来源互相矛盾

## 多空因素权重分析

对每条利好/利空因素评估两个维度：

1. **确定性**（高/中/低）：该因素发生的概率
2. **影响程度**（大/中/小）：对股价/业绩的影响幅度

优先关注「高确定性 + 大影响」因素，其次「高确定性 + 中影响」或「中确定性 + 大影响」。

```
             影响程度
               大      中      小
           ┌───────┬───────┬───────┐
确  高     │ 核心  │ 重要  │ 关注  │
          ├───────┼───────┼───────┤
定  中     │ 重要  │ 关注  │ 备注  │
         ├───────┼───────┼───────┤
性  低     │ 关注  │ 备注  │ 忽略  │
          └───────┴───────┴───────┘
```

## 估值分析框架

### 相对估值

1. **历史PE/PB区间**：从主要财务指标表提取近5年PE/PB数据，计算最小值/25分位/中位数/75分位/最大值/当前值/当前分位
2. **同业对比**：选择3-5家可比公司，对比PE/PB/ROE/增速/毛利率
3. **PE与利润增速匹配**：PEG = PE / 净利润增速，PEG < 1 可能低估

### 绝对估值

**DCF两阶段模型**（如数据充分）：
- 预测期：5年
- WACC估算：CAPM模型（无风险利率 + Beta × ERP）
- 永续增长率：2-3%（保守）
- 必须做敏感性分析

**股息估值**（如公司有稳定分红历史）：
- DDM或戈登增长模型
- 关注分红率可持续性（自由现金流覆盖率）

### 多方法汇总

各方法给出合理价格区间，按可靠性加权：

| 方法 | 权重建议 | 适用条件 |
|------|---------|---------|
| PE历史分位 | 25-30% | 盈利稳定 |
| 同业PE对标 | 20-25% | 可比公司充足 |
| DCF | 20-25% | 现金流可预测 |
| PB估值 | 10-15% | 重资产行业 |
| 股息估值 | 10-15% | 稳定高分红 |

## 避免认知偏差

分析时警惕以下偏差：

- **确认偏误**：只关注支持自己初步判断的信息。对抗方法：刻意寻找反面证据
- **近因效应**：过度重视最新数据而忽视长期趋势。对抗方法：强制回看3-5年数据
- **锚定效应**：被某个数字（如历史最高价）锚定判断。对抗方法：从多维度估值
- **幸存者偏差**：用成功公司对标而忽视失败案例。对抗方法：考虑行业平均水平
- **过度自信**：对预测过于确定。对抗方法：始终做情景分析（乐观/中性/悲观）

## 不确定性标记

报告中对不确定性使用统一标记：
- `[确定性高]` — 有充分数据支撑，大概率正确
- `[需要跟踪]` — 有一定依据但需要后续验证
- `[推测]` — 基于逻辑推理但缺乏直接证据
- `[分歧大]` — 市场对此存在严重分歧
