# 估值方法知识库

## 相对估值法

### PE（市盈率）

**适用**：盈利稳定、周期性弱的公司
**不适用**：亏损公司、强周期公司、利润波动剧烈

**估值逻辑**：合理股价 = 合理PE × 预期EPS

**合理PE确定方式**：
1. 历史PE分位法：近5年PE的25-75分位作为合理区间
2. 同业对标法：可比公司PE均值 ± 一个标准差
3. PEG法：PE = 未来3年净利润CAGR × (0.8~1.2)

### PB（市净率）

**适用**：重资产行业（银行、钢铁、化工）、PB-ROE 匹配分析
**不适用**：轻资产/互联网公司

**PB-ROE匹配**：ROE越高的公司应有越高的PB

### PS（市销率）

**适用**：高增长但尚未盈利的公司
**不适用**：盈利已稳定的公司

### EV/EBITDA

**适用**：不同资本结构/折旧政策公司之间的对比
**优点**：排除了税率、资本结构、折旧政策的差异

## 绝对估值法

### DCF两阶段模型

```
企业价值 = 预测期(5年)自由现金流现值 + 终值现值
股权价值 = 企业价值 - 净负债
每股价值 = 股权价值 / 总股本
```

**自由现金流** = 经营现金流 - 资本支出（或：EBIT×(1-t) + 折旧摊销 - 营运资本变动 - 资本支出）

**WACC估算（CAPM）**：
```
WACC = E/(D+E) × Ke + D/(D+E) × Kd × (1-t)
Ke = Rf + β × ERP
```
- Rf：10年期国债（中国约1.7-2.5%）
- ERP：中国市场常用5-7%
- β：近2年 vs 沪深300

**终值**：TV = FCF₅ × (1+g) / (WACC - g)

**必须做**：
- WACC ± 1% × g ± 0.5% 的敏感性矩阵
- 乐观/中性/悲观三情景

## 股息估值法

### DDM（戈登增长模型）

**适用**：稳定高分红公司（分红率>30%、盈利稳定）

P = D₁ / (r - g)

其中：
- D₁ = 预期下一年每股股息
- r = 要求回报率（通常取WACC或8-10%）
- g = 股息永续增长率（通常≤GDP增速，即2-4%）

**重要检查**：r > g，否则公式无意义。

## 行业特殊估值

### 创新药 — rNPV（风险调整净现值）

用于管线估值，将各在研药物按成功概率加权求和：
```
管线价值 = Σ (峰值销售额 × 成功率 × 现值因子)
企业价值 = 已上市产品DCF + 管线rNPV + 现金 - 负债
```

### 半导体 — 周期调整PE

半导体行业强周期性，使用：
- 过去一个完整周期（通常3-4年）的平均利润 × 合理PE
- 或 PB 法（周期底部看PB更可靠）

### 高增长公司 — 终局PE法

对于尚未盈利但有望扭亏的公司：
1. 预测稳态年份的利润（如5年后的"正常利润"）
2. 给予稳态PE
3. 折现回现在

## 常见估值陷阱

1. **用TTM PE看周期股**：利润高点PE看起来很便宜，实际是卖点
2. **忽视少数股东权益**：合并报表利润 ≠ 归母利润
3. **忽视股权激励稀释**：期权行权会摊薄每股价值
4. **DCF假精度**：DCF对终值假设极敏感，±1%的g差别可达30%以上
5. **对标选择偏差**：选择的可比公司不真正可比
6. **忽视资产负债表外项目**：经营租赁、或有负债等
